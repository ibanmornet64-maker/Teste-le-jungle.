# Logo officiel

Déposez ici le logo « Le Jungle Café » (PNG, JPG, WebP ou SVG), idéalement
carré et d'au moins 500 × 500 px. Nommez-le de préférence `logo.png` ou `logo.jpg`.

Le site le détecte automatiquement au prochain démarrage ou déploiement Vercel.
Il est alors utilisé dans le header, le footer, le menu mobile, le favicon,
l'icône d'écran d'accueil et les données Google.

Aucune ligne de code à modifier.
